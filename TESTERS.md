# Koollook tester pack

Plasma 6 only. Installs into the current user’s `~/.local` (no root).

```bash
tar -I zstd -xf koollook-2.6.0.tar.zst
cd koollook-2.6.0
chmod +x install.sh
./install.sh
kquitapp6 plasmashell; kstart plasmashell
```

Window decorations (System Settings → Window Decorations):

- **Koollook** — current glass/Willow bar (default)
- **Koollook Dotted** — KDE 2-style stippled title bar (separate option)

Colors: Koollook Dark, Aqua, Eesti, Liwi. Icons: Koollook (teal griffin launcher).
